# prof-whisperer

> Read your prof before they read your paper.

蒸馏你的课程老师，找到和他/她问题意识同频的论文选题，用苏格拉底式反问完成整个写作过程。目标只有一个：写一篇这位老师会给高分的论文。

---

## 安装

### 方法一：npx 一键安装（推荐）

```bash
npx skills add https://github.com/你的用户名/prof-whisperer.git
```

### 方法二：Git 克隆

```bash
git clone https://github.com/你的用户名/prof-whisperer.git ~/.claude/skills/prof-whisperer
```

### 方法三：手动安装

1. 下载本项目 ZIP 文件并解压
2. 将文件夹复制到 Claude Code 的 skills 目录：
   - macOS/Linux：`~/.claude/skills/`
   - Windows：`%USERPROFILE%\.claude\skills\`
3. 确保文件夹结构如下：

```
~/.claude/skills/prof-whisperer/
├── SKILL.md
├── README.md
└── references/
    └── examples.md
```

### 验证安装

重启 Claude Code 或重新加载 skills 后输入：

```
/prof-whisperer
```

## 使用

### 基础启动

```
/prof-whisperer 我有一门课要交论文，老师是 [姓名]，[院校] [系所]
```

### 提供更多信息（越多越准）

```
/prof-whisperer 老师叫 [姓名]，这门课叫 [课程名]
课程大纲里的核心阅读是 [书单]
老师上课反复强调 [某个观点]
论文要求 3000 字，下周交
```

### 上传作业反馈

```
/prof-whisperer 这是老师上次给我的评语：[反馈内容]
帮我根据这个反馈推断他/她的评分偏好
```

### 草稿修改

```
/prof-whisperer 这是我的论文草稿第二节：[粘贴文本]
帮我检查论证密度，用老师的眼光来问我
```

## 它做什么

### 两个模块，全程运作

**模块 A · 老师蒸馏**
搜索老师的论文、著作、课程大纲、访谈，提炼出「老师画像」：
- 核心问题意识（驱动他/她研究的深层疑问）
- 理论偏好与写作风格
- 评分雷区

**模块 B · 苏格拉底写作**
不直接给答案，通过反问逼你自己想通每一步：
- 选题：「老师没展开的那个角度是什么？」
- 文献：「去掉这篇，你的论证有洞吗？」
- 写作：「你跳过了哪个前提没建立？」
- 答辩：「你的新贡献是什么？」

### 选题的核心逻辑：问题意识同频

顺着老师容易被看穿不足，逆着风险太高。真正有效的选题是：你的研究问题和老师的问题意识在同一轨道，但你打开了他/她没有深入的那个角度。

老师读你的论文时应该感觉「这个学生真的在思考这个领域」，而不是「他在猜我喜欢什么」。

### 论证密度检查

社科写作最常见但最难被发现的问题：论点声称了，但中间步骤跳跃了——读者跟着你走，突然发现你跳过了一个关键步骤，但你当作已经证明了。

prof-whisperer 有专门的反问序列处理这个问题。

## 五个阶段

| 阶段 | 模块 A | 模块 B |
|------|--------|--------|
| 选题 | 提炼老师核心问题意识，找同频角度 | 「老师没展开的那个角度是什么？」 |
| 文献 | 检验每篇文献是否真正推进论点 | 「去掉它，论证有洞吗？」 |
| 框架 | 对照老师写作风格建议结构 | 「去掉这章，论点还成立吗？」 |
| 写作 | 扫描雷区 + 检查论证密度 | 「你跳过了哪个前提没建立？」 |
| 答辩 | 用老师关切生成最难问题 | 「你的新贡献是什么？」 |

## 适用范围

**适用：** 社会科学、人文学科的课程论文、期末论文、学位论文

**最有效的情况：**
- 能提供老师姓名 + 院校（可以搜索到老师的研究）
- 有课程大纲或阅读书单
- 有之前的作业反馈

**信息越少，画像越依赖学科通用规律；信息越多，指导越精准。**

---

## 学术伦理

prof-whisperer 帮你理解老师的学术期待，从而写出更有针对性的论文。了解评分者的偏好、读懂课程语境——这是真实学术写作的必要技能，不是捷径，是方法。

**不会做：** 代替你写论文、帮你套用结论、协助抄袭或任何学术不端。

**会做：** 帮你读懂老师关切，通过反问引导你自己想清楚，让你写的每个字都是你自己的，但方向更准。
